## 验收中完成的收口

- HTTP 模拟渠道支持 JDK 客户端的 chunked 请求，同时保持 4 KiB 请求上限和最小字段校验。
- `SHIPPED` 人工审核申请保留订单实付金额与币种；源订单金额不完整时，批准请求以业务冲突闭合失败。
- HTTP 退款请求只发送 `refundId、orderId、amount、currency`，并以相同 `refundId` 作为每次重试的 `Idempotency-Key`。
- 渠道成功但应用尚未收敛时主动停止进程；重启并等待租约到期后再次领取，退款效果仍保持唯一。

## 范围边界

本结论用于校招项目的工程可靠性证明，不是生产上线结论。验收不包含真实支付商、回调与验签、生产认证、双实例并发、MQ、Redis、压测、监控告警、部署设施或现场演示。
