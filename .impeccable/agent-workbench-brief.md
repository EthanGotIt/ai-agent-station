# Agent Workbench surface brief

- Scope and mode: `#/agent` is the default personal Operate workspace; `#/after-sales` and `#/memory` are adjacent task workspaces.
- Audience and job: the project author starts a real seeded scenario, then understands the complete Agent round without parsing raw SSE fragments.
- Proof and constraints: all prompts map to repository demo data and existing APIs. No fake metrics, production claims, stored browser preferences, or backend contract changes.
- Direction: Dispatch Ledger — graphite rail, mineral canvas, jade selections and vermilion write actions. A compact execution inspector makes technical evidence available without turning the conversation into a log viewer.
- Memorable moment: a one-click real scenario immediately becomes a readable conversation turn, while route, node, progress, tool and done events appear in the narrow inspector.
- Responsive and motion: desktop uses rail + canvas + inspector; mobile uses a bottom workspace nav and stacked panes. State feedback is 150–250ms, disabled under reduced motion.
- Resolved: approved comp `agent-workbench-dispatch-ledger-01.png` is the composition reference; all shared tokens belong in DESIGN.md after the finish review.
